# Excel Sales Data Pivot Dashboard

## Project Overview
This project is an interactive Excel Sales Dashboard created using a sales dataset.

## Tools Used
- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers
- Excel Dashboard

## Dashboard Features
- Total Sales KPI
- Total Profit KPI
- Total Quantity KPI
- Sales by Region
- Sales by Category
- Profit by Region
- Quantity by Category
- Profit by Category
- Interactive Region and Category Slicers

## Key Skills Demonstrated
- Data organization
- PivotTable analysis
- Data visualization
- Dashboard creation
- Interactive filtering
